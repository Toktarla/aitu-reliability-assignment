# AITU Reliability Engineering & Failure Analysis

This project contains Python calculation scripts and architectural diagrams for Assignment 1 (Fault Tolerance / Reliability Engineering) analyzing the synthetic AITU Student Information Portal context.

## Repository Structure
- `part_a_metrics.py` - Script calculating downtime, uptime, availability, MTTF, MTTR, and MTBF.
- `part_b_reliability.py` - Subsystem parallel/series reliability block calculations.
- `main.py` - Main runner script outputting aggregated results.
- `diagrams/` - Contains PNG diagrams for RBD and FTA.

## How to Run
Run the main calculation script using standard Python 3:
```bash
python main.py
```
